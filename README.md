# Projeto Amigo Secreto 🎁

Projeto-desafio proposto durante a trilha de desenvolvimento Front-end da formação Oracle Next Education em parceria com a Alura.
Para jogar o "Amigo Secreto" adicione os nomes dos participantes e deixe a sorte decidir quem tira quem!

## ✨ Funcionalidades

- **Adicionar Participantes:** Insira os nomes dos amigos no campo de texto e adicione-os à lista.
- **Validação de Nomes:** O sistema impede a adição de nomes em branco ou duplicados.
- **Remover Participantes:** É possível remover um amigo da lista a qualquer momento antes do sorteio.
- **Sorteio Simples:** Com um clique, o sistema sorteia um amigo secreto para você.

---

## 🚀 Tecnologias Utilizadas

O projeto foi construído utilizando tecnologias web padrões:

- **HTML5:** Para a estrutura e semântica do conteúdo.
- **CSS3:** Para a estilização, utilizando Flexbox e variáveis CSS para um design moderno e responsivo.
- **JavaScript:** Para toda a lógica de interatividade, como adicionar, remover e sortear os amigos.

---

## 🏁 Como Executar o Projeto

Como é um projeto front-end puro, não há necessidade de instalação de dependências. Basta seguir os passos:

1.  **Clone o repositório** para a sua máquina local:
    ```bash
    git clone https://github.com/seu-usuario/challenge-amigo-secreto_pt-main.git
    ```

2.  **Navegue até a pasta** do projeto.

3.  **Abra o arquivo `index.html`** no seu navegador de preferência (Google Chrome, Firefox, etc.).

> EXTRA: Caso queira executar o projeto em produção, você pode clicar [aqui](https://samchambela.github.io/desafio-oracle-one-amigo-secreto/)!

E pronto! Você já pode começar a adicionar os amigos e fazer o sorteio.

---

## 📝 Observação

A funcionalidade de sorteio atual revela um amigo secreto por vez. Após um sorteio ser realizado, os botões de adicionar e sortear são desabilitados para garantir a integridade do resultado. Para realizar um novo sorteio, basta atualizar a página.
